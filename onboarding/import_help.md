**会話の書き出し方**
- ChatGPT：設定 →「データコントロール」→「データをエクスポートする」
- Claude：設定 →「プライバシー」→「データをエクスポート」
- Gemini：ブラウザ拡張「Gemini Exporter」（ai-chat-exporter.com）で、会話を Markdown か JSON に書き出します

ChatGPT と Claude は、メールで届く zip ファイルをそのまま選べます。メールが届くまで時間がかかることがあります。

Gemini は、Google の「データ エクスポート」の書き出しには対応していません。同じ名前の別の拡張もあるので、配布元が ai-chat-exporter.com のものを使ってください。同じ配布元の「ChatGPT Exporter」「Claude Exporter」で書き出したファイルも選べます。

初期設定の途中なら、今は「会話ファイルなしで人物像づくりへ」で先に進み、迎えた後に設定の「記録とデータ」→「会話の取り込み」から取り込むこともできます。

書き出し方が分からない時は、普段使っている AI に聞いてみてください。
